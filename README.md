# 🔍 RetailLens — Amazon Sales Analytics Dashboard

End-to-end data analytics project on 1,21,180 Amazon India orders (Apr–Jun 2022)

## 📊 Key Insights
- Total Revenue: ₹7.86 Crore
- Avg Order Value: ₹649
- Cancellation Rate: 8.88%
- Top Category: Set (Clothing)
- Top State: Maharashtra
- Top City: Bengaluru

## 🗂️ Project Structure
- `notebooks/01_data_cleaning.ipynb` — Data cleaning & preprocessing
- `notebooks/02_eda.ipynb` — Exploratory Data Analysis
- `notebooks/03_product_analysis.ipynb` — Product & stock analysis
- `notebooks/04_pricing_analysis.ipynb` — Platform pricing comparison
- `notebooks/05_international_analysis.ipynb` — International sales
- `scripts/app.py` — Streamlit dashboard
- `scripts/analysis.sql` — SQL business queries
- `scripts/load_to_mysql.py` — MySQL data pipeline

## 🛠️ Tech Stack
Python | Pandas | Matplotlib | Seaborn | MySQL | Streamlit

## 📁 Dataset
- Amazon Sale Report — 1,21,180 rows
- Sale Report — 9,271 rows
- May-2022 Pricing — 1,330 rows
- International Sales — 36,391 rows
